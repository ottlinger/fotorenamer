Hilfe zum FotoRenamer



Hinweise zur Programmbenutzung:

  1. Bitte machen Sie eine Kopie Ihrer Kamerabilder!
  2. Starten Sie das Programm.
  3. Wählen Sie das Verzeichnis aus, welches die Sicherheitskopien der Bilder enthält. Sie können das Verzeichnis über den Auswahlknopf direkt wählen oder per Drag&Drop auf das Textfeld bestimmen.
  4. Betätigen Sie den Knopf

    "Starten"


Was tut das Programm?

Die Bilder auf Digitalkameras sind nach folgendem Schema benannt:

IMG_Nummer.jpg

Dadurch gibt es keine Information im Dateinamen, wann das Bild erstellt wurde.
Stattdessen nutzt das Programm die EXIF-Metadaten der Kamera und liest das ursprüngliche Erzeugungsdatum des Fotos nach folgendem Schema aus:

JJJJMMTT_HHMMSS_IMG_Nummer.jpg

Durch die Verwendung des ISO-Datumsformats lassen sich die Bilder alphabetisch sortieren, sodass eine Diashow einfacher möglich wird.
Beispiel

Aus der Datei

IMG_1865.jpg

wird die Datei

20031020_141713_IMG_1865.jpg

Das bedeutet, dass das Bild am 2003-10-20 um 14:17:13 Uhr aufgenommen wurde.
